# BLOCK FILL 기획서 (v1 확정)

## 1. 구성 요소
| 요소 | 내용 |
|---|---|
| 메인 보드 | 8×8. 시작 시 기본 블럭(회색) 10칸이 무작위로 깔린다 (14칸은 초반에 바로 끝나는 판이 18%였다) |
| 하단 트레이 | 블럭 3칸. 하나를 놓으면 그 칸에 즉시 무작위 새 블럭이 생긴다 |
| 블럭 | 기본형 24종, 회전 포함 64종 (`js/shapes.js`). 테트리스 7종(ㅡ·ㅁ·ㅜ·S·Z·ㄱ·ㄴ, 모든 회전)이 뽑기의 약 2/3, 작은 블럭(1~3칸) 약 15%, 큰 블럭(5칸 이상) 약 20%. 기본형마다 고유한 색이 있고 회전형은 같은 색 |
| 클리어 | 가로줄 또는 세로줄이 꽉 차면 제거 |
| 종료 | 세 블럭 모두 놓을 곳이 없고 블럭 교체를 살 포인트도 없을 때 |

## 2. 점수·포인트 (`js/config.js`)
- 점수(랭킹용)와 포인트(소비용)는 분리. 리프레시를 써도 점수는 줄지 않는다.
- 블럭을 놓으면 칸 수만큼 점수 +1.
- 줄 클리어: `클리어된 칸 수 × 10 × 동시 줄 배수 × 콤보 배수` 를 점수에 더하고, 그 60%(`pointsRate`)를 포인트에 더한다.
  - 동시 줄 배수: 1줄 1, 2줄 1.5, 3줄 2, 4줄 3, 5줄 4, 6줄 이상 5
  - 콤보 배수: 연속 클리어 1회당 +0.25, 최대 3배. 클리어 없이 놓으면 초기화
- 하단 블럭 교체: 50P에서 시작, 쓸 때마다 ×1.6 (50 → 80 → 128 → 205 …)
- 보드 리셋은 v1.9에서 제거 (새 판 시작과 같아 재미를 떨어뜨린다는 사용자 판단). 리프레시는 블럭 교체 하나뿐.
- 포인트와 비용 증가는 한 판 안에서만 유지된다.
- 시작 포인트: 모든 판 50P (블럭 교체 한 번 보장). 연속 출석 1일당 +10 (최대 7일 = +70P)은 일반 모드에만 적용.
- 밸런스 근거(v1.7, `design/progress.md` 반복 2): 사람에 가까운 봇 기준 한 판 중앙값 약 100수, 리프레시 8회, 20수 이내 종료 8%.

### 폭탄 (연쇄 반응, v2.2)
- 줄을 4개 지울 때마다(`bomb.linesPerBomb`) 폭탄이 1개 충전되고(최대 3), 다음에 뽑히는 블럭의 한 칸에 붙는다. 게이지는 블럭 교체 버튼 옆에 표시.
- 폭탄 칸이 지워지는 순간(꽉 찬 줄에 포함되거나 다른 폭탄의 십자에 걸리면) 그 칸의 가로줄·세로줄 전체(채워진 칸)가 터진다. 줄 2개로 계산해 점수·레벨·게이지에 들어간다.
- 십자에 걸린 다른 폭탄은 연쇄로 터진다(파동 순서는 `ev.waves`). 폭탄을 모아 한 번에 터뜨리면 쿼드러플·퍼펙트가 쉽게 나온다.
- 보드에 놓인 폭탄은 터질 때까지 그대로 있다. 레벨업 돌 낙하·블럭 교체에 영향받지 않는다.
- 숨겨진 폭탄(v2.3): 시작 기본 블럭 중 `hiddenInPrefill`(2)개, 레벨업 때 떨어지는 돌은 `hiddenInDrop`(35%) 확률로 폭탄을 품는다. 희미한 반짝임만 보이고, 그 줄이 지워지면 공개되며 십자로 터진다. 같은 시드면 자리도 같다.
- 연출(v2.3): 터질 폭탄 칸이 하얗게 맥동(점화 예고) → 화면 전체 섬광(파동마다 색이 바뀜: 주황→빨강→보라→하늘) → 3겹 충격파·굵은 십자 레이저와 그 자리를 따라 번지는 불길·회전 빛살 → 보드 펀치 줌 → "CHAIN ×N" 문구(커짐) → 폭죽(파동 수만큼), 3차부터 레이저 12방향. 숨은 폭탄은 하얀 섬광으로 공개.
- 업적 폭파 전문가·연쇄 폭발·대폭발, 미션 "폭탄 N개 터뜨리기" 추가.

### 레벨 (난이도 곡선, v1.8)
- 줄 6개를 지울 때마다 레벨 +1 (최대 12). 점수 카드에 `Lv.N`과 진행 바 표시.
- 레벨업 때 빈 칸에 기본 블럭이 `min(6, 레벨-1)`개 떨어진다 (줄을 완성시키는 자리는 피함).
- 레벨 1당 작은 블럭(1~3칸) 비중 −10%(하한 25%), 큰 블럭(5칸 이상) 비중 +12%.
- 보상: 줄 클리어 점수 배수 +10%/레벨 (레벨 12면 ×2.1).
- 시뮬레이션: 최선수 봇 170수 → 104수, 사람에 가까운 봇 85 → 79수 (`design/progress.md` 반복 3).

## 3. 경쟁 요소
- 랭킹: 친구/전체 × 이번 주/역대/오늘의 도전
- 친구 코드(6자리)로 서로 친구 맺기
- 플레이 중 "다음 목표 ○○ 님까지 N점" 표시, 추월 시 알림
- 일일 도전: 날짜로 시드를 고정해 모두 같은 판·같은 블럭 순서. 하루 1회
- 종료 화면: 친구 중 순위와 바로 위 친구와의 점수 차
- 연출(v2.1, `js/fx.js` 캔버스 파티클, 종이 조각 없음): "내 블럭이 줄을 공격한다" 순서로 — 놓은 자리에서 충격파·번개가 줄로 내리꽂힘 → 레이저가 줄을 따라 양쪽으로 쓸고 감 → 칸이 가까운 순서로 연쇄 폭발(빛점·불꽃·조각) → 점수가 점수판으로 날아가 달아오름.
  콤보 단계(2: COMBO, 3~: 🔥 HOT, 3줄·6콤보: ⚡ ON FIRE)별 문구·흔들림·폭발음·진동 패턴. 3단계부터 폭죽(로켓이 올라가 터짐), 4단계는 레이저 12방향 방사.
  콤보가 이어지는 동안 보드 테두리가 타오름(열기 1~3단계). 보드를 다 비우면 PERFECT 레이저 십자·폭죽 5발, 레벨업은 빛살·폭죽 3발·불기둥. 움직임 줄이기 설정이면 파티클 생략.
- 진동: 놓기 12ms, 클리어 단계별 패턴(1단계 짧게 → 4단계 길고 거칠게), PERFECT·레벨업·블럭 교체 각각. 지원하지 않는 기기는 무시.
- 결과 이미지 공유: 점수·보드 스냅샷·주소가 담긴 PNG를 공유 시트로 보내거나 저장
- 첫 실행 시 게임 방법 안내(한 번), 기록 화면에서 다시 볼 수 있음
- 오프라인에서도 경쟁: 내 역대 기록(최근 30판)을 목표로 "내 3위 기록까지 N점" 표시, 넘으면 알림. 종료 화면에 내 역대 순위
- 오늘의 미션(`js/missions.js`, v1.9): 날짜 시드로 모두 같은 목표 3개(줄 N개, 더블 N회, 3콤보, 한 판 점수, 레벨, N판, 대청소, 일일 도전). 달성 1개당 그날 일반 모드 시작 포인트 +20P. 자정(KST)에 초기화
- 업적 19종(`js/achievements.js`): 더블·트리플·콤보·점수·출석 등. 달성 시 알림, '최고 기록' 카드를 눌러 기록·업적 확인

## 4. 조작·화면
- 드래그 앤 드롭(터치·마우스). 놓일 자리와 지워질 줄 미리보기
- 화면: 상단(모드·랭킹·친구·소리·계정) → 점수/최고/포인트 → 다음 목표 → 보드 → 트레이 → 리프레시 2종

## 5. 기술·데이터 보존
- 빌드 없는 정적 사이트(HTML + ES 모듈). GitHub Pages 배포. 홈 화면에 추가하면 앱처럼 전체 화면으로 열림(manifest)
- 서버: Supabase (인증 + Postgres). 계정·점수·친구는 서버에 있으므로 게임 업데이트와 무관하게 유지
- 기기 저장(`blockfill.save`): 진행 중인 판, 설정, 미전송 점수. 버전 번호 + `migrate()`로 이전
- 규칙과 화면 분리: `js/game.js`는 DOM 없이 동작 → `node tests/game.test.mjs`
